**🦾 <a href="https://github.com/Abhishek4452/ROBOTIC_ARM">Joystick-Controlled Robotic Arm</a>**

A 4-DOF robotic arm controlled using analog joysticks and Arduino. Implemented real-time ADC acquisition, joystick signal filtering, dead-zone handling, position mapping, and smooth servo control. The project provided hands-on experience in embedded control, signal processing, and hardware debugging.
